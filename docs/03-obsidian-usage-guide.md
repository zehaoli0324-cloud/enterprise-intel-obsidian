# Obsidian 使用方法（企业情报数据库实战版）

> 版本：v1.0 · 2026-08-26
> 配套 demo：本仓库 `demo/` 文件夹（可对照本指南实际操作）。
> 本文假设你已经会基本的文件操作，只讲情报库会用到的功能。

---

## 0. 打开 demo（第一步）

1. 打开 Obsidian 桌面版
2. 左下角仓库名 → 「打开其他仓库」→「打开文件夹作为仓库」
3. 选择本仓库的 `demo/` 文件夹（或任意一份情报 vault 目录）
4. 界面出现三栏：左侧文件列表 / 中间编辑区 / 右侧面板（可切「关系图谱」）

---

## 1. 核心概念（3 个就够）

### 1.1 笔记 = 一个节点

每个 `.md` 文件就是一个"节点"。在情报库里：

| 节点类型 | 例子 |
|---------|------|
| 公司 | `01-公司/富瀚微.md` |
| 人物 | `02-人物/杨小奇.md` |
| 产品 | `03-产品物料/IPC网络摄像机SoC.md` |
| 投资人 | `04-投资人/联想控股.md` |
| 事件 | `05-交易事件/2020-09-联想控股战略入股富瀚微.md` |

### 1.2 [[wikilink]] = 一条关系（图谱的边）

在笔记里写 `[[富瀚微]]` 就在两篇笔记之间建立连接。demo 里的关系都是这么表达的：

```
[[联想控股]] → 投资 → [[富瀚微]]
[[富瀚微]] → 供货 → [[海康威视]]
```

输入 `[[` 会自动弹出候选笔记，选一个即可。

**为什么这很重要**：Obsidian 的"关系图谱"就是把所有笔记当点、所有 [[wikilink]] 当线画出来的图。你的企业情报库在图上就是一张供应链/股权网络。

### 1.3 YAML frontmatter = 结构化字段（可查询）

每篇笔记开头有一个 `---` 包裹的块，存放机器可读的属性：

```yaml
---
type: company
name: 上海富瀚微电子股份有限公司
code: 300613.SZ
industry: 集成电路设计（视觉/视频芯片）
customers: "[[海康威视]]"
---
```

**字段即数据库的列**。后面用 Bases/Dataview 查询时，就是按这些字段筛选、排序、出表格。

## 2. 关系图谱（情报库最常用的视图）

打开方式：右侧面板点击「关系图谱」（图标像三个点连线），或快捷键 `Ctrl/Cmd + G`。

### 基本操作

| 操作 | 方法 |
|------|------|
| 看全局图 | 打开图谱面板，拖动/滚轮缩放 |
| 聚焦某公司 | 点击某个节点，高亮它的所有直接关联 |
| 局部图 | 在某篇笔记内打开「局部关系图」（右侧面板→更多选项），只看它的一度/二度关系 |
| 筛选 | 图谱面板→筛选条件，按 tags 或路径过滤 |
| 着色 | 图谱面板→分组依据→Tags（如 type: company / person / product），一眼分辨实体类型 |

### demo 里你应该看到

打开 `00-总目录.md` 的局部图，应能看到：

- 中心簇：[[富瀚微]] 连接 [[联想控股]]、[[海康威视]]、[[杨小奇]]、[[陈春梅]]、[[中芯国际]]…
- 第二簇：[[全志科技]] 连接 [[比亚迪]]、[[萤石网络]]、[[瑞芯微]]…
- 桥节点：[[中芯国际]]/[[台积电]]/[[联电]] 同时连着两家公司（供应链重叠）
- 竞争边：[[富瀚微]] ↔ [[全志科技]]（笔记正文里的互链）

## 3. 表格查询（把数据库"查出来"）

### 3.1 用 Obsidian 内置的 Bases（新版核心插件）

1. 新建一篇笔记，比如 `查询-所有公司.md`
2. 插入 → Bases → 表格
3. 选择数据源：标签 `#type/company` 或文件夹 `01-公司`
4. 表格自动列出所有公司笔记，frontmatter 字段变成列
5. 点击列头排序、筛选

### 3.2 用 Dataview 社区插件（进阶，可选）

安装：设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜 Dataview → 安装启用。

然后在任意笔记里写：

```dataview
TABLE industry, region, code
FROM #type/company
WHERE region = "上海"
```

就能把上海的公司列成表格。更复杂的查询（按字段筛选、按关系聚合）看 Dataview 官方文档。

## 4. 模板（建库效率工具）

1. 设置 → 核心插件 → 启用「模板」
2. 设置模板文件夹路径为 `_模板`
3. 新建笔记 → 插入模板 → 选 Company / Person / Product…

demo 的 `_模板/` 里已有 5 个模板（Company/Person/Product/Investor/Deal），字段与目录结构配套。

## 5. 维护规范（让图谱不烂掉）

| 规则 | 原因 |
|------|------|
| 一条信息一个来源 URL | 防 AI 幻觉、可回溯 |
| 每次更新写 `07-变更日志/` | 知道数据什么时候来的、改了什么 |
| 重名笔记用全路径链接 `[[01-公司/富瀚微]]` | 同名文件会让图谱连线失效 |
| wikilink 不要写在 frontmatter 和代码块里 | 图谱不渲染它们 |
| 文件名不要用 `&` 等特殊字符 | Windows 文件系统陷阱 |
| 重命名笔记 | Obsidian 会自动更新所有引用（放心改名） |

## 7. 与 Hermes 的配合（回顾）

Obsidian 只负责"人看"。让 Hermes（AI 代理）自动采集、抽取、写入这些笔记，就得到完整的情报系统：

1. Hermes 搜索公司资料 → 按模板生成笔记草稿（带来源 URL）
2. 人工核对关键关系 → 修正后入库
3. Hermes cron 定时巡检 → 变更写入 `07-变更日志/`
4. 人在 Obsidian 图谱里看结果

架构细节见《02-企业情报数据库-架构与Proposal.md》。
