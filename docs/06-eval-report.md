## 3. 结论与短板

### 优点（被验证）
1. **建库过程克制**：50 条抽样 0 幻觉——"未验证不写"原则生效，尤其股权类全部对应东财十大股东数据
2. **Abstention 正常**：无来源聚合页标 UNKNOWN，不编造
3. **Entity Resolution 无冲突**：全部实体单名制（台积电/联电/中芯国际），无重复别名

### 短板（诚实记录 + 2026-08-26 修复状态）

| 短板 | v1 时状态 | 修复状态 |
|------|----------|---------|
| 🔴 Evidence Precision 低（关系行内缺 URL） | 关系行 0% 带 URL | ✅ **已修**：自动从节点 source_url 继承，147/184 行（80%）带来源；35 个聚合行 + 2 行目标无源未补（已知） |
| 🟡 Temporal 不完整 | 部分关系缺时间戳 | 🟡 **部分修复**：4 行补年份、1 行补历史标注；temporal-report.md 记录时间敏感关系清单；关系行层时间信息本身稀疏（时间主要在事件节点），v2 需关系行强制带年份 |
| 🟡 INFERRED 细节混在正文 | 细节与主关系同级展示 | 未修（v2：关系级 confidence 显示） |

> 关系行来源引用脚本逻辑：独立关系行从目标节点 frontmatter source_url 自动继承追加（`（来源: URL）`），幂等（已有 URL/来源 字样跳过），聚合行（一行多实体）跳过。时间戳：desc 含年份 → 追加 `（信息年份: YYYY）`；含历史/曾/原 → 追加 `（历史信息）`。
