# 导入方案：把 Enterprise Intel DB 导入你自己的 Obsidian 库

> 版本：v1.0 · 2026-08-26
> 适用：拿到本仓库/zip 后，想把它并进自己已有 Obsidian 库的人。

先判断你的场景，选一种方案：

| 方案 | 适合谁 | 难度 | 冲突风险 |
|------|--------|------|---------|
| A. 独立打开 | 只想要这套情报库，不影响现有库 | 最低 | 无 |
| B. ingest 再生 | 想要内容融进自己的库、且愿意用 YAML 管理 | 中 | 无 |
| **C. 直接合并** | 想整库并进现有库，文件已现成 | 中 | 低（脚本自动处理） |

---

## 方案 A：作为独立库打开（最快，2 分钟）

1. 下载 zip：https://github.com/zehaoli0324-cloud/enterprise-intel-obsidian/releases/download/v0.1.0/enterprise-intel-demo-vault.zip
2. 解压 → 得到 `enterprise-intel-demo/` 文件夹
3. Obsidian 桌面版 → 左下角仓库名 →「打开其他仓库」→「打开文件夹作为仓库」→ 选择该文件夹
4. 右侧打开「关系图谱」即可看到供应链/投资/竞争网络

**适合**：先体验效果；或你本来就用多个 vault 管理不同主题。

---

## 方案 B：用 ingest.py 重新生成（推荐，最干净）

不复制 demo 文件，而是把数据源（YAML）跑进你自己的库，自动生成节点和关系，**零冲突、零残留**。

1. 把示例关系文件复制到你的工作目录：`examples/relations-demo.yaml`
2. 按需修改（加你自己的公司/关系）
3. 在你的库上生成：

```bash
python3 scripts/ingest.py <你的vault路径> -f relations-demo.yaml --dry    # 先预演
python3 scripts/ingest.py <你的vault路径> -f relations-demo.yaml          # 正式生成
```

4. 打开 Obsidian → 图谱里出现新节点，与你的现有笔记通过反链自然连接

**适合**：你只想保留"实体 + 关系"的数据模型，不想要 demo 里的分析页/示例内容；或者你的库已经很大，不想复制文件。

---

## 方案 C：整库合并进现有库（脚本自动处理冲突）

### 第 1 步：下载并解压

同上，下载 zip 解压，或直接 clone 仓库用 `demo/` 目录作为源。

### 第 2 步：冲突预检（不写文件）

```bash
python3 scripts/import-helper.py <源库demo目录> <你的vault路径> --check
```

输出三组数字：
- **可安全复制** —— 直接复制，不冲突
- **内容相同跳过** —— 你库里已有完全相同文件，跳过
- **冲突(将重命名)** —— 你库里有同名但内容不同的文件，导入时会复制为「企业情报-原名.md」，**不会覆盖你的文件**

### 第 3 步：执行合并

```bash
python3 scripts/import-helper.py <源库demo目录> <你的vault路径> --merge
```

合并规则（安全设计）：
- 复制所有 `.md` 到你的库，保持目录结构（`01-公司/`、`02-人物/`…）
- **同名不同内容** → 复制为 `企业情报-原名.md`，并把新文件内部的 `[[原名]]` 引用自动改写为 `[[企业情报-原名]]`，保证新图谱不裂
- **你的 `00-总目录.md`** → 不被覆盖；导入的索引存为 `企业情报-00-总目录.md`
- **不碰你已有的任何文件**（同名相同则跳过）
- 模板（`_模板/`）和脚本（`scripts/`）一并复制

### 第 4 步：验证

1. 打开 Obsidian → 看图谱，重点检查是否有"红点"（断裂链接）
2. 入口：打开 `企业情报-00-总目录.md` 或任意新节点，看反链是否正常
3. 确认你的旧笔记都在（脚本只增不改）

## 常见问题

**Q：我库里有同名笔记（如"海康威视"），会覆盖吗？**
不会。同名不同内容 → 导入版改名 `企业情报-海康威视.md`，你的原文件原封不动。两者图谱上各自独立。

**Q：改名后新文件里的 wikilink 断了吗？**
脚本已自动改写新文件内部对改名文件的引用（`[[海康威视]]` → `[[企业情报-海康威视]]`）。实测合并后 0 断裂链接。

**Q：导入后想删除这套内容怎么办？**
删掉 `01-公司/` ~ `07-变更日志/` 文件夹 + `企业情报-*.md` + `_模板/` 里对应模板即可，不影响你原有内容。

**Q：不想用脚本，手动复制行吗？**
可以，但注意三点：同名文件手动覆盖会破坏你的旧笔记；同名不同目录会让 Obsidian 的裸 `[[名字]]` 链接失效；模板同名会被覆盖。建议用脚本。

**Q：导入的内容会出现在我的图谱里，太乱了怎么办？**
Obsidian 图谱支持筛选：按路径过滤（只看 `01-公司` 等）、按标签分组（`#type/company` 着色）、或只看局部图。

**Q：我用的不是 demo 库，是另一个情报库？**
同一套工具：`import-helper.py` 的源路径换成任意 Obsidian 库目录即可（通用合并器）。

## 三种方案怎么选（一句话）

- 想体验 → **A**
- 只要数据模型、内容自建 → **B**
- 想要现成整套、并进自己库 → **C**
