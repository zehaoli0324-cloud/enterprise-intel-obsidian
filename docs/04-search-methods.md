# 搜索方式与信息渠道（企业情报采集方法论）

> 版本：v1.0 · 2026-08-26
> 本文档记录本 demo 实际用到的数据源与搜索方法，可直接复用。
> 原则：**一手优先、多源交叉、每条事实带来源 URL 和采集时间。**

---

## 1. 渠道总览（按可信度排序）

| 优先级 | 渠道 | 内容 | 方式 |
|--------|------|------|------|
| P0 | 东方财富行情/F10 API | 股价、市值、股本、十大股东、主营、核心题材 | HTTP JSON API（免费，无需登录） |
| P0 | 巨潮资讯网（cninfo） | 上市公司年报/公告原文 | 网页/PDF |
| P1 | 公司官网 + 官方公众号 | 产品线、合作新闻 | 网页 |
| P1 | 主流财经媒体（新浪/和讯/每经/腾讯） | 事件报道、采访 | 网页 |
| P2 | 通用搜索引擎（360 搜索/Sogou） | 聚合线索 | 网页 |
| P3 | 股吧/财富号/雪球（二手分析） | 深度分析、竞争格局 | 网页（**需交叉验证**） |

**可信度规则**：P0 数据（API 的股东/财务）> P1 媒体（事件）> P2 聚合 > P3 分析贴。P3 的量化数字（占比、金额）必须有 P0/P1 佐证才能入库。

## 2. 上市公司结构化数据（东方财富，免费 API）

### 2.1 实时行情与基础指标

```
GET https://push2.eastmoney.com/api/qt/stock/get?secid={市场}.{代码}&fields=f57,f58,f43,f84,f85,f116,f117,f162,f167,f168,f169,f170,f171,f173,f186,f187
```

- 市场：0=深市（300/000/002），1=沪市（600/601/603/688）
- 例：富瀚微 `0.300613`，全志科技 `0.300458`
- 常用字段：f57 代码 / f58 名称 / f43 最新价(×100) / f84 总股本 / f116 总市值 / f162 市盈率(动) / f186 毛利率 / f187 净利率

### 2.2 公司概况与核心题材（主营/行业/客户线索）

```
GET https://emweb.securities.eastmoney.com/PC_HSF10/CoreConception/PageAjax?code=SZ300613
```

- 代码格式：`SZ`/`SH` + 6 位代码
- 返回 JSON：`hxtc[]` 含 KEYWORD / MAINPOINT / MAINPOINT_CONTENT（经营范围、主营、行业分析、公司亮点）
- 客户/供应商线索常出现在"市场优势/客户稳定优势"类目

### 2.3 十大股东（投资方/实控人验证）

```
GET https://emweb.securities.eastmoney.com/PC_HSF10/ShareholderResearch/PageAjax?code=SZ300613
```

- 返回 `sdgd[]`：HOLDER_NAME（股东名）、HOLD_NUM_RATIO（持股比例）
- **用途**：验证"谁投资了谁"——股东名 + 持股比例是股权投资关系的硬证据

### 2.4 主要财务指标

```
GET https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_F10_FINANCE_MAINFINADATA&columns=ALL&filter=(SECUCODE%3D%22{代码}.SZ%22)&pageNumber=1&pageSize=5&sortTypes=-1&sortColumns=REPORT_DATE
```

- SECUCODE 格式：`300613.SZ`
- 返回各报告期财务数据（营收/净利/ROE 等）

### 2.5 注意事项

- 请求头加 `User-Agent: Mozilla/5.0` 即可，无需登录
- 接口字段会不定期调整，抓取时先打印原始 JSON 确认字段名
- 市值/价格是实时值，入库时记录采集时间

## 3. 通用中文搜索（线索发现）

### 3.1 360 搜索（curl 直接可用）

```
curl -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120.0" \
  "https://www.so.com/s?q={URL编码关键词}" -o result.html
```

解析技巧：结果 `<a>` 标签带 `data-mdurl="真实URL"` 属性，直接取真实 URL，**不要**走 so.com/link 跳转（需 cookie）。

示例关键词模式：
- `{公司A} 前五大客户 {公司B}` —— 验证客户关系
- `{公司A} {公司B} 竞争` —— 验证竞争关系
- `{公司A} 晶圆 代工 供应商` —— 找上游
- `{机构} 入股 {公司}` —— 找投资事件

### 3.2 搜狗搜索（备用，限流严格）

```
https://www.sogou.com/web?query={URL编码关键词}
```

- 实测限流：同一会话约 1 次查询机会，之后触发 CAPTCHA。**一枪一命**：选好关键词一次挖完。
- 结果链接是跳转页，需二次提取 `window.location.replace("真实URL")`。

### 3.3 不可用渠道（勿浪费时间）

- 百度：滑块验证码，无法绕过
- Google：WSL 环境返回 400
- Bing CN：结果质量差/Cloudflare 拦截

## 4. 行业深挖（竞争格局类）

| 场景 | 渠道 | 示例 |
|------|------|------|
| 竞争格局文章 | 行业媒体（物联网世界、与非网、半导体行业观察） | "端侧AI芯片争霸赛"类综述点名玩家 = 直接竞争证据 |

| 公司互动 | 上证 e 互动 / 深交所互动易 | 董秘回复是准一手信息（如"芯片主要由中芯国际、台积电、联电代工"） |

## 5. 验证纪律（防幻觉，必须执行）

1. **关键关系至少 2 个独立来源**：投资入股（媒体 + 十大股东 API）、大客户（年报 + 媒体）、代工（董秘回复 + 媒体）
2. **区分事实与预期**：媒体说"未来可能供芯片"是预期，不写成事实，标"待核实"
3. **标注来源层级**：每条入库事实写 source_url + fetched_at；二手分析（股吧/财富号）明确标注
4. **量化数字溯源**：占比/金额必须有出处；找不到出处的数字不写或标"训练数据未验证"
5. **人名/公司名模糊匹配**：同名不同人/公司时，用股权、代码、地域交叉验证（如"联想投资富瀚微"须确认是联想控股体系，不是联想集团 PC 业务）

## 6. 采集工作流（本次 demo 的实操顺序）

```
1. 东财 API 拿基础面（市值/股本/主营/十大股东）→ 确定公司画像
2. 360 搜索事件关键词（投资/客户/竞争）→ 找新闻线索
3. 抓 2-3 篇权威报道交叉验证关键关系
4. 东财/互动易确认代工、供应商等细节
5. 整理：每条事实 = 值 + 来源 URL + 采集日期 → 写入 Obsidian 节点
6. 变更日志记录本次新增/修改
```
