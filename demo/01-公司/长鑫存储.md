# 长鑫存储

**国产 DRAM 唯一规模量产企业**（IDM 模式：设计+制造一体），运营主体为长鑫科技。

## 业务

- 产品：DDR4 / DDR5 / LPDDR 系列，中端 DRAM 全系列量产；向 15nm 节点、DDR5 与 HBM 高端存储演进
- 地位：全球 DRAM 市场由三星 / SK海力士 / 美光垄断，长鑫是国产替代主力
- IPO：2026-07-16 开启科创板网上申购，年内 A 股最大 IPO，募资 295 亿元（申购代码 787825）
- 业绩（报道口径）：存储超级周期下 2026 上半年预计净利润 500-570 亿元，待招股书核实
